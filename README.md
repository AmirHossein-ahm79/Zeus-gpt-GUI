<div dir="rtl">

<h1 align="right">⚡ Zeus GPT</h1>

<p align="right">
<strong>Zeus GPT</strong> یک <strong>AI Study Planner</strong> است که با استفاده از هوش مصنوعی، بر اساس هدف یادگیری، سطح کاربر و زمان در دسترس، یک مسیر یادگیری شخصی‌سازی‌شده ایجاد می‌کند.
</p>

<h2 align="right">✨ قابلیت‌ها</h2>

<ul dir="rtl">
<li>🤖 تولید Roadmap با هوش مصنوعی</li>
<li>🎯 برنامه‌ریزی بر اساس هدف و سطح یادگیری</li>
<li>⏱️ در نظر گرفتن زمان مطالعه روزانه</li>
<li>📚 ارائه مباحث و تمرین‌های هر مرحله</li>
<li>🇮🇷 رابط کاربری فارسی و RTL</li>
<li>🌙 طراحی Dark و Responsive</li>
<li>⚡ رابط کاربری ساده و سریع</li>
</ul>

<h2 align="right">🛠️ تکنولوژی‌ها</h2>

<p align="right">
<strong>Frontend:</strong> HTML, CSS, JavaScript
</p>

<p align="right">
<strong>Backend:</strong> Python, http.server, Requests
</p>

<p align="right">
<strong>AI:</strong> OpenRouter API
</p>

<h2 align="right">📂 ساختار پروژه</h2>

</div>

```text
Zeus-gpt-GUI/
├── app.py
├── index.html
├── requirements.txt
├── run.bat
└── README.md
```

<div dir="rtl">

<h2 align="right">🚀 اجرا</h2>

<p align="right">
ابتدا Repository را Clone کنید:
</p>

</div>

```bash
git clone https://github.com/AmirHossein-ahm79/Zeus-gpt-GUI.git
cd Zeus-gpt-GUI
```

<div dir="rtl">

<p align="right">
سپس وابستگی‌های پروژه را نصب کنید:
</p>

</div>

```bash
pip install -r requirements.txt
```

<div dir="rtl">

<p align="right">
در مرحله بعد، API Key مربوط به <strong>OpenRouter</strong> را در فایل <code>app.py</code> قرار دهید و پروژه را اجرا کنید:
</p>

</div>

```bash
python app.py
```

<div dir="rtl">

<p align="right">
پس از اجرا، وارد آدرس زیر شوید:
</p>

</div>

```text
http://127.0.0.1:8000
```
